# ♠ Der Pik-Dame-Code

Ein Escape Room für zwei, für Lauri & Noah zum Monatstag.

**Spielen:** https://n0ahwag.github.io/pik-dame-code/

1. Ruft euch an. 📞
2. Beide öffnen die Seite, einer wählt **Spieler 1 (Noah)**, die andere **Spieler 2 (Lauri)**.
3. Gleicher Raumcode bei beiden (Standard: `lauri-noah`).
4. Beide auf „Bereit“, dann geht's los. Dauer: ca. 2 Stunden.

Bitte nicht im Code nach Lösungen suchen. 😉 Für jedes Kapitel gibt es im Spiel drei Tipps.

Die Abschlussnachricht steht in `js/nachricht.js`. Die Datei enthält keine Spoiler.
